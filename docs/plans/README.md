# Plans

Execution plans for changes larger than one file. Name them
`YYYY-MM-DD-<slug>.md` and start each with a `Status:` line
(`active`, `completed` or `abandoned`), then keep a progress list and a decision
log as the work moves. `tools/test_doc_links.py` checks every plan has a status.

Known debt that no plan owns yet lives in [tech-debt.md](tech-debt.md).
